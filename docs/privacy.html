CHIARO, COME DOVREBBE ESSERE

La tua privacy,
senza giri di parole.

Qui spieghiamo quali dati riguardano il sito e il browser Cosmic, quali richieste avvengono e quali controlli hai a disposizione.

Ultimo aggiornamento: 17 novembre 2026

In breve: il codice del sito non imposta cookie propri né usa analytics. La versione attuale del browser non include telemetria o sincronizzazione cloud gestite dal progetto. I siti che visiti, il motore di ricerca scelto e GitHub possono comunque ricevere le richieste necessarie alle funzioni che usi.

1. A chi si applica

Questa informativa riguarda il sito pubblico di Cosmic e l'applicazione desktop Cosmic per Windows, Linux e Mac con Apple Silicon. Cosmic è un progetto indipendente e open source. Non gestiamo un servizio di account o sincronizzazione online.

2. Il sito web

Il sito è pubblicato tramite GitHub Pages. Il codice del sito non imposta cookie propri, non integra pixel pubblicitari e non usa servizi di analytics propri.

Per mostrare numero di versione, data e link diretti ai pacchetti, il sito richiede al browser i metadati dell'ultima release tramite l'API pubblica di GitHub. La richiesta va direttamente a GitHub e può includere l'indirizzo IP e i normali dati tecnici di connessione. Anche GitHub, in qualità di fornitore di hosting/API, può trattare dati tecnici secondo le proprie informazioni sulla privacy.

I link a GitHub e ai siti di terze parti aprono servizi esterni, soggetti alle rispettive informative.

3. Il browser Cosmic

Nella versione attuale, il codice del progetto non include una funzione di telemetria che invii agli sviluppatori cronologia, ricerche, segnalibri, password o statistiche d'uso. Non è prevista sincronizzazione cloud: impostazioni, segnalibri, sessioni, cache e profili gestiti da Cosmic sono salvati sul dispositivo.

Quando navighi, il browser comunica con i siti e le risorse che quei siti caricano. Quando cerchi dalla barra o dalla nuova scheda, il testo della ricerca viene inviato al motore impostato (DuckDuckGo per impostazione iniziale, modificabile nelle impostazioni). Questi servizi ricevono le richieste secondo le proprie regole e informative.

Il controllo manuale degli aggiornamenti in Impostazioni → Aggiornamenti interroga l'API GitHub delle release; quando scegli di scaricare, il download avviene da GitHub. Cosmic non esegue il controllo aggiornamenti in background.

4. Protezioni e scelte disponibili

  • Il blocco delle richieste verso domini pubblicitari e di tracciamento noti è attivo inizialmente e si può disattivare. È basato sul dominio: non elimina gli elementi pubblicitari già mostrati e non intercetta ogni forma di tracciamento.
  • Cosmic invia inizialmente il segnale Do Not Track. I siti possono ignorarlo: non è una garanzia di blocco.
  • I cookie possono essere conservati tra le sessioni; puoi scegliere di mantenerli solo per la sessione e cancellarli alla chiusura.
  • Le richieste di accesso a posizione, microfono, videocamera e notifiche chiedono il tuo permesso per impostazione iniziale; le preferenze sono modificabili.
  • L'archivio password è facoltativo, resta sul dispositivo ed è protetto da una password principale.

5. Conservazione e cancellazione

I dati di navigazione e le preferenze che Cosmic salva restano nei dati locali dell'applicazione finché non li cancelli o rimuovi. Puoi cancellare cookie e cache dalle impostazioni, attivare i cookie di sola sessione, modificare i permessi o rimuovere i dati locali dell'app dal tuo dispositivo. La disinstallazione potrebbe non cancellare automaticamente i dati del profilo.

Il sito non conserva un profilo utente Cosmic. I dati tecnici eventualmente trattati da GitHub seguono le politiche di conservazione di GitHub.

6. Account e modifiche

Per usare il browser non è richiesto un account online. Se cambiano in modo significativo le funzioni o i flussi di dati, aggiorneremo questa pagina indicando la nuova data.

7. Domande

Per domande sul progetto puoi aprire una segnalazione nel repository GitHub di Cosmic. Non pubblicare in una segnalazione informazioni personali, password o altri dati riservati.
